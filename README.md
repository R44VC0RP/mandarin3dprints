# Mandarin3D

A 3D-printing resource site and MDX blog built with Next.js, React, and Tailwind CSS. Blog posts live in `content/blog`.

Use Node.js 22.18 or later and npm. No environment variables or external services are required.

## Development

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```sh
npm run build
npm start
```
