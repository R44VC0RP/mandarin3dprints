This guide covers the file itself: export, mesh inspection, repair, and checking the sliced result. A clean mesh is not proof that a part will fit or carry a load. Those decisions belong in the [design-modification guide](/blog/why-your-3d-model-might-need-modifications-before-printing).

## 1. Keep the Source and Export a Copy

Save the editable CAD or modeling file before changing anything. If the source contains a solid-model error, fix it there rather than repeatedly repairing exported meshes. Name the export with its revision so the repaired file cannot be confused with the original.

STL is widely supported but stores triangles without declared units. Binary STL is normally smaller than ASCII STL. 3MF can store units and additional manufacturing information, but compatibility depends on the receiving software and the features used. See the [STL, OBJ, and 3MF comparison](/blog/understanding-3d-file-formats-stl-vs-obj-vs-3mf) before choosing a handoff format.

Export curved surfaces finely enough to avoid visible facets, but do not maximize triangle count by default. Chord deviation describes how far the mesh may depart from the original curve; a smaller value usually produces more triangles. Inspect small holes and curves at the intended print size. There is no universal triangle count or file-size limit that suits every model and slicer.

## 2. Reopen the Export and Check Scale

Measure one known dimension after importing the exported file. An inch interpreted as a millimeter is a 25.4-fold size error, not a small tolerance problem. Also check that every intended body exported and that hidden construction geometry did not.

Do not repair a scale error by eye. Correct the units or apply the known conversion, then verify the dimensions again. Keep room in the target build volume for supports, brims, and printer exclusion zones.

## 3. Identify the Actual Mesh Problem

For a conventional closed solid mesh, each boundary edge should belong to two faces. An open edge belongs to only one; an edge shared by more than two faces is non-manifold. Other problems include self-intersections, duplicate faces, zero-area triangles, and inconsistent face directions. Flipped normals are not the same thing as an open hole, even though both can confuse interpretation.

Multiple disconnected shells are not automatically errors. They may represent intentionally separate parts. Likewise, a modeled through-hole has closed walls around its opening; it is different from missing triangles in the surface.

The slicer converts geometry into toolpaths. It may reject ambiguous surfaces, repair them, or interpret them differently from the modeling application. That is why a model's appearance in a viewer is not sufficient verification.

## 4. Repair With Supported Tools

Start with the source model or your current slicer's documented repair tools. Support varies by platform and version. Inspect every repair rather than treating an "auto repair" message as a guarantee.

For manual mesh work, Blender's [3D Print Toolbox extension](https://extensions.blender.org/add-ons/print3d-toolbox/) provides geometry analysis and repair tools. Install the compatible extension rather than assuming it is bundled. Work on a copy, identify the flagged region, and compare the result with the intended shape. Filling every opening or rebuilding a surface can erase an intentional cavity or alter a mating feature.

Older tutorials often recommend tools that are no longer good starting points:

- Microsoft confirms that [3D Builder became unsupported and was removed from the Store in July 2024](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features). Do not depend on installing it for a new workflow.
- Autodesk says [Meshmixer is no longer in development or supported](https://marketplace.autodesk.com/apps/2e40e347-0369-4603-b83f-ecab324aed0f). An existing installation may still work, but it is a legacy option.
- [Autodesk Fusion with Netfabb](https://www.autodesk.com/products/netfabb/overview) is a commercial product offering, not a promise that an old free online repair link remains available.

Avoid uploading confidential models to an unfamiliar repair website. Check its data-handling terms and your permission to share the file first.

## 5. Inspect the Layers, Not Just the Solid Preview

Slice using the intended printer, nozzle, and material profile. Step through the layer preview around repaired regions. Check whether walls disappear, a cavity becomes filled, a disconnected feature starts in midair, or supports become trapped where they cannot be removed.

Compare the repaired file with the original dimensions and silhouette. If a repair changes a fit-critical feature, return to the source model or get approval before production. A watertight mesh describes a closed digital surface; it does not mean the printed object will hold liquid.

Once the exported file is verified, use the [print-service handoff checklist](/blog/preparing-your-3d-model-for-printing) to communicate units, quantity, material, and the approved revision.
